# HTML Forms Project

## Overview

This project contains three HTML files demonstrating basic HTML forms, Bootstrap forms, and a registration form with validation.

## Files

- `index.html` — Part 1: Basic contact form and HTML5 validation.
- `index1.html` — Part 2: Bootstrap contact form and Bootstrap validation styles.
- `index2.html` — Part 3: Responsive registration form with validation.

## Technologies Used

- HTML5
- Bootstrap 5
- JavaScript

## How to Run

1. Download or extract the project files into one folder.
2. Open `index.html`, `index1.html`, or `index2.html` in a web browser.
3. An internet connection is needed to load Bootstrap from its CDN for Parts 2 and 3.
4. Enter information into the forms and submit them to test validation.

## Features

- Labels for form fields.
- HTML5 validation attributes such as `required`, `type`, and `minlength`.
- Bootstrap styling and responsive grid layout.
- Validation feedback for valid and invalid fields.
- Registration fields for names, email, passwords, gender, hobbies, and country.
- Submit and reset buttons.

## Note

The forms demonstrate client-side validation only. They do not send or save information to a server or database.
